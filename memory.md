## Durable notes

- Preserve custom authorization architecture and last-administrator safeguards.
- Adding a **platform** permission touches: `App\Enums\PermissionSlug` case, `AuthorizationSeeder` (display-name map + `$platformAdminPermissionSlugs`), `tests/Feature/Authorization/AuthorizationCatalogueTest.php` counts, `docs/authorization.md`. Company-scoped: only `CompanyMemberRole::permissions()`.
- **Framework boot order:** app providers boot BEFORE framework's EventServiceProvider. To remove framework listeners (e.g. `SendEmailVerificationNotification` on `Registered`), do it inside `$this->app->booted(fn () => Event::forget(...))` in `AppServiceProvider::boot()` — a plain `Event::forget` in `boot()` runs too early and is silently undone. No app listeners are registered on `Registered` (auth audits listen to Login/Logout/PasswordReset).
- **Queuing mail:** Laravel sends notifications synchronously unless they implement `ShouldQueue`. Pattern: subclass the framework notification with `implements ShouldQueue`, override `sendEmailVerificationNotification()` on the model; dispatched via `database` queue; requires a running worker (`composer dev` / `queue:listen`); without one, mail accumulates silently in `jobs`. phpunit uses `QUEUE_CONNECTION=sync`.
- **Verification semantics (Feature 38):** point-in-time (post-approval email change un-verifies; admin badge + disabled action; reactivate gated too). `email_verified_at` stays unsettable (not fillable; admin payloads expose boolean `email_verified` only — never the timestamp).
- **App-name vs logo:** env APP_NAME is "Job Application"; committed brand assets are NextStep; user reserved renaming decision — recommend setting APP_NAME/VITE_APP_NAME to NextStep on their go-ahead (single env edit).
- Feature 36/37 permission mapping: company-scoped `applicants.view` / `applicants.manage`; evaluations append-only; notes author-only + live `applicants.manage`.
- JobFactory sets random `application_deadline` — tests must pin it; `Job::status` is not `$fillable`.
- `composer ci:check` must run **unpiped** in PowerShell. `npm run build` regenerates Wayfinder (`resources/js/actions`); `verify-email` chunk appears in manifest only after build.
- `php artisan dev` = serve + vite + `queue:listen` + reverb (`dev:list` shows all four); `queue` process is required for any queued job, else rows pile up in `jobs` unobserved.
- MySQL/InnoDB owns FK backing indexes; second-precision timestamps need monotonic tiebreak (`orderByDesc('id')`).

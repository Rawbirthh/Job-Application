## Durable notes

- Preserve custom authorization architecture and last-administrator safeguards.
- Adding a **platform** permission touches four places: `App\Enums\PermissionSlug` case, `AuthorizationSeeder` (display-name map **and** the `$platformAdminPermissionSlugs` allow-list), the hard-coded counts in `tests/Feature/Authorization/AuthorizationCatalogueTest.php` (23 → 24 → 25 → 26 …), and the catalogue table in `docs/authorization.md`. Adding a **company-scoped** permission touches only `App\Enums\CompanyMemberRole::permissions()`. Keep the two namespaces' slugs distinct (`analytics.view` vs `platform_analytics.view`).
- Keep route permission middleware and Policy checks authoritative on the server. Navigation visibility is presentation only.
- **Never hold mutable state on a service or controller.** Laravel caches the resolved controller — and therefore its injected services — on the `Route` object, so a memoised value is served stale on the next read. Compute aggregates per call.
- **MySQL/InnoDB owns foreign key backing indexes.** It silently drops a redundant FK index when a covering index is added, and refuses to drop an index a FK depends on. Guard every index DDL in a migration with `Schema::hasIndex()` and make `up()`/`down()` idempotent; restore FK backing indexes before removing composites. Verify migrations on MySQL, not only on the SQLite test suite.
- `AuditLogService::sanitizeValue()` now accepts `null` metadata values (they were previously a thrown `RuntimeException` that the fail-soft write path swallowed, silently dropping the audit row). Keep `resources/js/types/audit-log.ts` in sync with the PHP enums.
- Rebuild frontend assets (`npm run build`) after modifying controller actions or route definitions used by Wayfinder.
- Feature 6–9 deferred delete protections active via `restrictOnDelete` FKs on `job_postings`.
- Company members scoped per company; never grant platform-admin permissions.
- Report moderation never auto-removes content; actual removal goes through job moderation (`jobs.moderate`) / employer suspension (`employers.manage`).
- Audit trail (Feature 31): append-only, admin-only, no write routes; audit writes inside business transactions are fail-closed, while auth events and read-path writes (audit-log reads, analytics reads) are fail-soft.
- Never store `.env` values, credentials, tokens, private keys, or personal data here.
- `memory.md` is a formatted file: `npm run check` (prettier via vp) checks it in CI, so always run `npx vp check --fix memory.md` after editing it by hand, before committing.
